# Dataset Description

## Overview

This dataset contains rendered microscope-style filter membrane fields for microplastics triage benchmarking. Each image shows a membrane field with pores, fibers, fragments, bead-like particles, film-like translucent particles, clogging, glare, biofilm haze, low contrast, stain shifts, and edge or ring-biased debris patterns.

The raw data is generated by the included deterministic script `generate_raw.py`. The generator records hidden scene traces and derives multiple-choice acquisition/triage answers from those traces. The public task requires reading the membrane image and triage prompt together; trace columns are removed during preparation.

This is a field-of-view triage cue dataset, not a single-label particle classifier. Several questions can refer to the same membrane field, and each question asks about a different operational cue relevant to manual microplastics review.

## Raw Upload File Structure

| File or Folder | Rows / Files | Description |
|---|---|---|
| `data.csv` | 2,880 rows | One row per triage cue with raw IDs, image path, prompt, choices, answer label, hidden groups, and trace fields. |
| `images/` | 480 PNG files | Rendered 160x160 RGB microscope-style filter membrane fields. |
| `generate_raw.py` | 1 file | Deterministic generator with fixed random seed. |

## Prepared Challenge File Structure

The prepare script remaps raw IDs to opaque IDs, copies images to public hashed filenames, performs a scene-level train/test split, and removes hidden trace columns. It creates the following prepared files for the challenge:

| File or Folder | Rows / Files | Public or Private | Description |
|---|---|---|---|
| `public/train.csv` | 2,016 rows | Public | Labeled training questions with `question_id`, `scene_id`, `image_path`, question text, choices, `question_type`, and `answer_label`. |
| `public/test.csv` | 864 rows | Public | Unlabeled test questions with `question_id`, `scene_id`, `image_path`, question text, choices, and `question_type`. |
| `public/sample_submission.csv` | 864 rows | Public | Example submission with `question_id` and placeholder `answer_label`. |
| `public/images/` | 480 PNG files | Public | Opaque renamed 160x160 RGB membrane-field images referenced by train and test rows. |
| `private/answers.csv` | 864 rows | Private | Ground-truth test answers plus hidden evaluation groups: `question_type`, `difficulty`, `visibility`, `layout_family`, and `ood_axis`. |

## Raw Columns

| Column | Type | Description |
|---|---|---|
| `question_id` | string | Raw question identifier. |
| `scene_id` | string | Raw image/field identifier. |
| `image_path` | string | Relative path to the PNG membrane-field image. |
| `question_type` | categorical string | Triage cue being tested. |
| `question` | string | Multiple-choice question text. |
| `choice_a`, `choice_b`, `choice_c`, `choice_d` | string | Answer choices shown to solvers. |
| `answer_label` | categorical string | Correct answer: A, B, C, or D. |
| `difficulty` | categorical string | Hidden group: easy, medium, or hard. |
| `visibility` | categorical string | Hidden condition: clear, low_contrast, glare, biofilm, or overloaded. |
| `layout_family` | categorical string | Hidden particle layout family: centered, edge_loaded, ring_bias, or diagonal_streak. |
| `ood_axis` | categorical string | Hidden shift such as standard, blue_stain, edge_shadow, or bubble_ring. |
| `trace_dominant_particle_family` | categorical string | Generator trace for dominant family. Removed from public files. |
| `trace_hotspot_quadrant` | categorical string | Generator trace for densest quadrant. Removed from public files. |
| `trace_fiber_tint` | categorical string | Generator trace for dominant fiber tint. Removed from public files. |
| `trace_bead_count` | integer | Generator trace count of round beads. Removed from public files. |
| `trace_bead_count_bin` | categorical string | Generator trace binned bead count. Removed from public files. |
| `trace_clogging_state` | categorical string | Generator trace clogging state. Removed from public files. |
| `trace_qc_action` | categorical string | Generator trace next triage action. Removed from public files. |
| `trace_density_index` | integer | Generator trace particle-density proxy. Removed from public files. |

## Triage Cue Types

| Type | What It Tests |
|---|---|
| `dominant_particle_family` | Identify whether fibers, fragments, beads, or films dominate the field. |
| `hotspot_quadrant` | Locate the densest suspicious-particle hotspot quadrant. |
| `fiber_tint` | Identify the most common visible fiber tint. |
| `bead_count` | Count round bead-like particles in binned ranges. |
| `clogging_state` | Identify open pores, edge clogging, central mat clogging, or patchy multi-zone clogging. |
| `qc_action` | Select whether to count now, reimage focus, dilute/refilter, or send for manual review. |

## Data Characteristics

The data intentionally mixes particle morphology and quality-control cues. Some fields are clear and sparse; others are overloaded, low-contrast, glare-affected, or partially masked by biofilm-like haze. The private split is scene-level, so no test question shares its membrane image with training rows. Hidden groups support reviewer analysis of performance across difficulty, visibility, layout, and OOD-style shifts.
